## Рекомендации по фиксации результата

1. Используйте сборку именно с проверяемого candidate SHA. Запишите `kdockw --version` и Git SHA.
2. Для динамических сценариев сохраните видео с видимым действием и результатом. Не используйте лог или макет вместо видео.
3. Запишите ожидаемое/фактическое поведение, тип окна (Wayland или XWayland), приложение и воспроизводимость.
4. Не изменяйте системные переменные локали, драйверы или KWin-настройки ради прохождения теста. Если проверяется NVIDIA PRIME service override, фиксируйте это отдельно как конфигурацию стенда.
5. Перед публикацией приложите доказательства к release review и укажите все непроверенные сценарии.
