# KDockW v0.5.1 — Draft Release Notes

> Draft for the unreleased v0.5.1 candidate. This document is not a release announcement; no tag or GitHub Release has been created.

KDockW v0.5.1 focuses on Wayland dock geometry and Fedora 45 / Qt 6.11 compatibility.

## Changes

- Preserved the existing Layer Shell surface on screen unlock when its screen, edge, size, visibility mode, and reservation parameters have not changed. The owner confirmed that a maximized browser remained aligned with KWin's `MaximizeArea` after lock/unlock on Plasma 6.6.6 / Wayland.
- Added the **Gap to maximized windows** setting. It adds an independent 0–20 logical-pixel reservation between the dock and maximized windows, updates live, persists across restarts, and defaults to 0 px. The gap is applied on all four dock edges through the native Layer Shell exclusive zone. Auto Hide and Dodge Windows retain their existing non-reserving behavior.
- Added Fedora 45 / Qt 6.11.2 to the v0.5.1 candidate matrix after the full Fedora Distro E2E passed.

## Verification status

The local candidate matrix passed: Production Release CTest **180/180**;
Diagnostic Release CTest **181/181**; Debian 13 **210 passed / 21 skipped / 0
failed**; Ubuntu 26.04 **218 / 13 / 0**; Fedora 45 / Qt 6.11.2 **218 / 13 / 0**.

The first Ubuntu full run's single Preview timing failure is preserved in its
artifacts. The test was corrected to measure AT-SPI geometry lookup separately
from pointer dispatch without changing the 190 ms dispatch limit; the complete
Ubuntu rerun passed.

These notes remain a draft pending owner verification of the current candidate
in a real Plasma/Wayland session, including lock/unlock, fullscreen, Auto Hide,
Dodge, dock edges, and TaskManager/window previews. No release assets or
publication are implied by this file.
