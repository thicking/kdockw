# KDockW 0.5.1 release notes

KDockW 0.5.1 improves dock geometry and application menu behavior on KDE Plasma 6 / Wayland, and adds support for Fedora 45 with Qt 6.11.

## Changes

- The dock keeps its existing Layer Shell surface across screen unlock when its output, edge, size, visibility mode, and reservation settings are unchanged. The owner accepted the maximized-browser lock/unlock behavior on Plasma 6.6.6 / Wayland.
- The new **Gap to maximized windows** setting reserves a saved 0–20 logical-pixel gap through Layer Shell, applies changes immediately, and supports all four dock edges. It defaults to 0 px; Auto Hide and Dodge Windows keep their existing reservation behavior.
- Application context menus retain Desktop Actions, pinning, new-instance, and notification actions. Settings, About KDockW, and Quit KDockW are grouped in a KDockW submenu. Closing a single window is separate from closing a grouped application's windows.
- TaskManager presentation remains current when Qt 6.11 replaces launcher rows with running windows.
- Fedora 45 / Qt 6.11 is included in the required package and Distro E2E matrix.
- The preview fast-pointer regression check measures pointer dispatch separately from AT-SPI geometry lookup and retains the 190 ms dispatch threshold.
