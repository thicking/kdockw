# KDockW 0.5.1 — примечания к выпуску

KDockW 0.5.1 улучшает геометрию дока и поведение контекстного меню в KDE Plasma 6 / Wayland, а также добавляет поддержку Fedora 45 с Qt 6.11.

## Изменения

- При разблокировке сохраняется прежняя Layer Shell surface, если не менялись экран, сторона, размер, режим видимости и параметры резервирования дока. Владелец подтвердил сценарий с maximized-браузером после блокировки и разблокировки Plasma 6.6.6 / Wayland.
- Новая настройка **«Зазор между доком и окнами»** задаёт сохраняемый зазор 0–20 логических пикселей через Layer Shell, применяется сразу и работает со всеми четырьмя сторонами дока. По умолчанию — 0 px; Auto Hide и Dodge Windows сохраняют прежнее поведение резервирования.
- В контекстных меню приложений сохранены Desktop Actions, закрепление, запуск нового экземпляра и действия уведомлений. «Параметры…», «О KDockW» и «Выйти из KDockW» объединены в подменю KDockW. Закрытие одного окна отделено от закрытия окон сгруппированного приложения.
- Представление TaskManager обновляется при структурной замене строк запускаемого приложения работающими окнами в Qt 6.11.
- Fedora 45 / Qt 6.11 включена в обязательную матрицу сборки пакетов и Distro E2E.
- Проверка быстрой передачи указателя в предпросмотре теперь отдельно измеряет задержку отправки указателя и чтения геометрии AT-SPI; предел 190 мс сохранён.
