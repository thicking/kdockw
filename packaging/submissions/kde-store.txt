KDockW is a compiled desktop dock for KDE Plasma 6 on Wayland. It combines pinned application launchers and running applications, with parabolic icon zoom, PipeWire window previews, configurable layout and multi-monitor support.

KDockW is not a Plasmoid, widget, KPackage, or Get New Widgets add-on. Build it from source using the instructions in the release README:
https://github.com/{{repository}}/blob/{{tag}}/README.md#build--run
