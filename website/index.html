KDockW

A native dock for KDE Plasma, with smooth parabolic zoom, grouped windows, and live previews.

KDockW is an independent project based on Krema. It keeps the original project’s required notices and Git history while developing its own application identity and features.

Source code Build instructions NVIDIA PRIME guide Migration guide

Made for Plasma on Wayland

  • Magnify dock icons with a fluid parabolic zoom.
  • Group application windows and switch between them from the dock.
  • Pin desktop launchers, reorder items, and drop files onto applications.
  • Use KDE-native settings, keyboard navigation, and Russian localization.

Origins and license

KDockW is based on Krema, originally created by Byeonghoon Yoo. It is developed independently and remains licensed under GPL-3.0-or-later.
