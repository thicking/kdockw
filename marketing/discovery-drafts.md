## KDE Discuss

**Suggested title:** KDockW — a KDE Plasma 6 Wayland dock with parabolic zoom and live window previews

Hi everyone,

I have been developing KDockW, an independent dock for KDE Plasma 6 on Wayland
based on Krema. The current stable release is v0.3.1. It includes parabolic
icon zoom, grouped applications, live previews for open and minimized windows,
keyboard navigation, and configurable panel appearance.

The project is distributed through GitHub Releases. Packages and the supported
release-test targets are documented in the repository. The site and source are
below; I would especially value feedback from Plasma users about the dock's
integration and day-to-day behavior.

- Project: https://github.com/thicking/kdockw
- Latest release: https://github.com/thicking/kdockw/releases/latest
- Demo and screenshots: https://thicking.github.io/kdockw/

## r/kde

**Suggested title:** KDockW: an independent Plasma 6 / Wayland dock with live previews

KDockW is an independent KDE Plasma 6 dock based on Krema, developed as a
spiritual successor to Latte Dock. The v0.3.1 release has parabolic zoom,
window grouping, live previews for open and minimized windows, launch feedback,
and KDE-integrated settings.

I built it for my own Plasma desktop and would appreciate practical feedback
from other KDE users. Source, install instructions, packages, and a short demo:

- https://github.com/thicking/kdockw
- https://github.com/thicking/kdockw/releases/latest
- https://thicking.github.io/kdockw/
