# План разработки KDockW

KDockW — независимая док-панель для KDE Plasma 6 / Wayland и духовный
преемник Latte Dock. Этот план описывает только работу над KDockW и не
копирует и не продолжает архивный план Krema. Пункты задают приоритеты, а не
сроки выпуска или обещания версий. См. [план на английском](ROADMAP.md),
[историю KDockW](CHANGELOG.md) и [архивный план Krema](docs/history/krema-roadmap.md).

## v0.4.0 — macOS-like Spring Physics (выпущен)

KDockW v0.4.0 опубликован 2026-11-09 из проверенного коммита `main`.
Подписанный тег, пакеты и манифест SHA-256 доступны на странице
[релиза GitHub](https://github.com/thicking/kdockw/releases/tag/kdockw-v0.4.0).
Обязательный Distro E2E прошёл на Debian 13, Ubuntu 26.04 LTS и Fedora 45:
[запуск workflow 42609893460](https://github.com/thicking/kdockw/actions/runs/42609893460).

- [x] **Spring Magnification (`done`):** добавлена физика пружины с настройками
  упругости, демпфирования и скорости отклика. В новых конфигурациях включён
  Spring (170 / 0,60 / 1,0; увеличение 1,9×); сохранённые значения не меняются,
  Classic остаётся доступен. Владелец принял анимацию в реальной Plasma/Wayland;
  тесты с ограниченным шагом моделируют 60/120/144 Гц.
- [x] **Анимация показа и скрытия дока (`done`):** добавлено настраиваемое
  выдвижение с затуханием (включено по умолчанию, 220 мс) только в режимах,
  где скрытие уже предусмотрено; задержка скрытия дока настраивается отдельно
  (500 мс по умолчанию). В скрытом состоянии ввод ограничен краевой полосой
  активации. Владелец принял анимацию и взаимодействие на реальной KDE
  Plasma/Wayland 2026-11-08.
- [x] **Задержка скрытия предпросмотра окон (`done`):** добавлена отдельная
  задержка 0–1500 мс (по умолчанию 400 мс), отменяемая при возврате указателя.
  Владелец принял поведение в KDE Plasma/Wayland 2026-11-08.
- [x] **Launch & Attention Animation (`done`):** амплитуда подпрыгивания при
  запуске постепенно уменьшается; для него настраиваются интенсивность и
  скорость. Анимация внимания запускается только по явным сигналам срочности,
  ограничена по времени и оставляет спокойный индикатор, пока запрос сохраняется.
  При одновременных событиях приоритет у запуска. Добавлено короткое
  подпрыгивание Click Bounce при активации, восстановлении или сворачивании уже
  запущенного приложения; оно не запускается при наведении и не заменяет Launch
  Bounce. Высота Launch Bounce настраивается относительно размера значка.
  Владелец подтвердил Launch Bounce, Click Bounce и Attention Animation на
  Plasma 6.6.6 / Wayland; длительность Attention по умолчанию — 3 секунды,
  явно сохранённые значения остаются без изменений.

**Зависимости:** Spring Magnification следует после принятой геометрии v0.2.0 и
отдельного технического долга по профилю Classic zoom. Показ/скрытие зависит от
стабильной геометрии surface/input region. Анимации запуска и внимания остаются
независимыми.

## Область проекта

KDockW предназначен для KDE Plasma 6 на Wayland и использует Qt 6 и KDE
Frameworks 6. Проект развивается самостоятельно на основе оригинального
[Krema](https://github.com/isac322/krema), созданного Byeonghoon Yoo. Старые
выпуски и планы Krema сохранены в [`docs/history/`](docs/history/); они не
являются выпусками или обещаниями KDockW.
