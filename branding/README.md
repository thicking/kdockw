# KDockW brand assets

The KDockW mark is an original vector asset. It uses a K-shaped dock silhouette,
a zooming row of tiles, and a blue, cyan, and violet palette. The icon masters
are `logo/kdockw-icon.svg` and `logo/kdockw-icon-small.svg`; app and website PNG
exports are generated from those files.

The checked-in PNGs were rendered from the SVG master with Qt's
`QSvgRenderer`; sizes are 16, 22, 24, 32, 48, 64, 128, and 256 px.

The current repository also retains inherited assets named `krema-*` and
upstream screenshots/social cards. They document the project's origin; they
are not KDockW logos and must not be used in new KDockW materials. The
KDockW-generated app icons and favicons are separate files. Do not alter source
file copyright notices, the GPL license, or original Git authorship as part of
branding work.
